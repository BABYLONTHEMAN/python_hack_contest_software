# Python Hack Contest Software

Small beginner Python contest/autograder structure.

## Files

```txt
q1_goal_parser/
├── solution.py
└── test.py

q2_clear_digits/
├── solution.py
└── test.py
```

Each question has:

- `solution.py` = student answer file
- `test.py` = teacher/platform checker file

## Run Q1

```bash
cd q1_goal_parser
python solution.py
```

## Run Q2

```bash
cd q2_clear_digits
python solution.py
```
